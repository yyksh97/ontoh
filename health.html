ONTOH CARE

간편인증 한 번으로 10년치 건강검진을 자동 수집하는
작업자 보건관리 시스템.

근로자의 건강 위험을,
데이터로 먼저 살핍니다.

검진 결과·업무 적합성·직종 유해인자를 하나의 흐름으로 관리해, 고위험군을 사전에 선별합니다.

문의하기

ONTOH CARE가 보건관리를 자동화하는 방법.

01 / 04

01

건강검진 결과 입력 · 관리

  • 작업자 건강 상태 등급 분류
  • 업무 적합성 결과 입력 · 관리
  • 위험군 사전 선별 · 관리
  • 카카오 · 네이버 · PASS 간편인증
  • 10년치 국가건강검진 자동 연동
  • 수기 입력 제거 · 오류율 0%

02

업무 적합성 결과 입력 · 관리

  • 업무수행 적합성 결과 입력 · 정리
  • 조건별 적합성 정보 일괄 관리
  • 현장 배치 기준으로 활용

03

공종 · 직종별 위험인자 참고

  • 직종 / 공종 선택 및 분류
  • 선행연구 기반 주요 위험인자 제공
  • 작업 환경별 안전관리 기준 마련

04

유해인자별 건강구분 및 사후관리 조치

  • 유해인자 자동 매칭 및 검색
  • 건강등급 기반 관리 기준 적용
  • 사후관리 및 조치 가이드 확인

관리자는 대시보드, 작업자는 모바일 앱.

관리자는 현장 전체 현황을 집계하고, 작업자는 자신의 건강 상태를 이해합니다.

관리자 뷰

대시보드로 현장 전체를 관리

등록 작업자 · 고위험군 · 미등록자 현황을 실시간으로 집계합니다.

  • 민감군 대시보드 — 현장별 고위험군 실시간 파악
  • 미등록자 알림 — 미등록 작업자 자동 식별 · 등록 독촉
  • 유해인자별 검진결과 조회 — 건강구분 · 조치 현황 확인
  • 엑셀 출력 & 조치완료 체크 — 기존 보고 양식과 호환

작업자 뷰

모바일 앱으로 개인 건강 확인

공단 검진 데이터를 시각화해 자신의 건강을 쉽게 이해합니다.

  • 건강나이 — 공단 검진 기반 직관적 표시
  • 심뇌혈관 위험 예측 — 3년 내 발병 확률 분석
  • 유사집단 비교 — 동일 연령 · 성별 · 직종 집단
  • 연도별 건강 추이 — 10년 시계열 시각화

관리 부담을 덜어주는 부가 기능 4가지.

건강등급별 대응 가이드 자동 생성

건강등급에 맞춰 필요한 조치 · 관찰 · 배치 가이드를 자동으로 생성합니다.

직종 기반 유해인자 자동 로그

직종 · 공종 이력을 따라 노출된 유해인자가 자동으로 기록됩니다.

리포트 자동 생성 · 엑셀 출력

현장별 · 개인별 보건 리포트를 자동 생성하고 엑셀 출력을 지원합니다.

사후 관리 자동 리마인드

건강 이력을 모니터링하고 재검사 · 작업전환 리마인드를 자동 발송합니다.

수기 보건 업무를 자동화로 바꿔보세요.

현장 규모와 작업자 수에 맞춰 최적의 도입 방안을 설계해 드립니다.
