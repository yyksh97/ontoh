도입 사례 · LOOKAT

실제 현장 도입 · LOOKAT 단일 솔루션 적용.

개요

수도권에 조성 중인 대규모 조성 지구(약 135만㎡·8,000세대급)에서, 광범위한 부지에 흩어진 고정 CCTV만으로는 실시간 위험 감지가 어려웠습니다. LOOKAT 도입 후 PTZ 자율관제로 사각지대를 해소하고, 위험행동 감지부터 법령 연동 보고서까지 자동화했습니다.

과제

넓은 부지, 고정 CCTV의 한계

부지가 넓고 공정에 따라 작업 위치가 계속 바뀌면서, 고정 화각 CCTV로는 사각지대가 상시 발생했습니다. 기존 지능형 CCTV는 단순 감지·알람만 제공해 오경보가 과다했고, 안전관리자는 하루 대부분을 영상 확인과 수기 보고서 작성에 소모했습니다.

  • 고정 CCTV 사각지대로 위험행동 실시간 포착 곤란
  • 오경보 과다로 관제 신뢰도·집중도 저하
  • 일일 안전보고서 수기 작성 부담

적용

기존 CCTV에 AI를 얹어, 스스로 위험을 찾아내다

장비 교체 없이 기존 CCTV 인프라를 그대로 활용했습니다. AI가 PPE 미착용·개구부·위험구역 침범을 식별하면 PTZ 카메라가 자율적으로 회전·줌·추적하고, RAG-LMM이 상황을 복합 판단해 오경보를 줄였습니다. 감지 내용은 관련 법령과 자동 대조되어 증빙·보고서로 정리됩니다.

  • 기존 CCTV 활용 — 장비 교체 없이 소프트웨어로 적용
  • PTZ 자율 제어 — 사각지대를 능동적으로 추적
  • 법령 자동 연동 — 감지 → 증빙 → 보고서 원스톱

성과

사각지대 해소와 업무 자동화를 동시에

  • 위험행동 자동 감지 일 평균 40+건 — 사람이 놓치던 상황까지 포착
  • 오경보 68% 감소 — 유효 알림 중심으로 관제 집중도 향상
  • 보고서 작성 2시간 → 10분 — 안전관리자 업무 부담 대폭 경감
  • 위험 감지 후 알림까지 평균 1초 이내

법령 대응

감지·기록·보고 체계로 국내 안전 법령 요건 충족 지원

해외 안전관리 AI 솔루션에는 없는 한국 법령 대응이 온토의 차별화 축입니다.
